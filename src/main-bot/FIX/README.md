# FIX - AdaptiveBot + Bot1 Mix

Strategi:
- AdaptiveBot: movement acak dan wall avoidance.
- Bot1: greedy attack berdasarkan jarak.
- Radar sensor diperluas sedikit menggunakan sweep stabil 70 derajat.
- Gun hanya diarahkan saat musuh ter-scan, lalu fire.

## Build
```bash
dotnet build
```

## Run
```bash
dotnet run
```

Atau:
```bash
chmod +x FIX.sh
./FIX.sh
```
